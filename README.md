# Ahlumile Totose — Vue Portfolio

A personal portfolio website rebuilt as a Vue 3 + Vite single-page application. It showcases my projects, skills, learning journey, and contact information in a more maintainable component-based structure.

## Overview
This portfolio was migrated from the original HTML/CSS version into a Vue.js project with reusable components and structured pages for:
- Home
- About
- Projects
- Contact

## Tech Stack
- Vue 3
- Vite
- JavaScript
- HTML
- CSS
- Git & GitHub

## Features
- Component-based Vue architecture
- Responsive design for desktop and mobile
- Reusable project cards with images and hover effects
- Project gallery with project details and links
- Skills and learning goals sections
- About page timeline and personal reflection
- Contact form section and achievements

## Run the Project
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for Production
```bash
npm run build
```
